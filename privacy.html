Privacy Policy

Effective 2026-11-15. This policy covers the OAuth client used by a personal, single-user OpenCode integration. It has one user: the owner of the Google account that authorizes it.

Who this applies to

This application is not distributed and cannot be installed by anyone else. It is authorized against one Google account, by that account's owner, to let two programs running on that owner's own computer access that same account. There are no other users, and no way to become one.

What data is accessed

Only what the owner's own requests require, within the scopes granted at authorization:

  • Gmail: messages, threads, labels, filters, and mailbox settings — read and modified to perform the operation the owner asked for, such as searching mail or applying a label.
  • Google Calendar: the calendar list, events, and event details — read to answer the owner's scheduling questions.

Nothing outside those scopes is requested or reachable. Authorization tokens are issued by Google and can be revoked at any time (see below).

Where that data goes

It goes exactly two places: the owner's computer, and Google's APIs. Requests travel directly from the local process to googleapis.com over HTTPS. There is no intermediary server, no hosted backend, no cloud database, and no third-party processor of any kind.

Nothing is sold, rented, shared, published, or used for advertising. There is no analytics, telemetry, crash reporting, tracking pixel, or advertising identifier in this application.

What is stored, and where

  • OAuth tokens — access and refresh tokens, stored as files on the owner's local disk, in the owner's own user profile. They are not encrypted by this application and are not transmitted anywhere except to Google's token endpoint.
  • Configuration — the OAuth client identifier and, locally, the client secret required by Google's installed-app flow, in a local file.

Mail and calendar content is not copied into any database or long-term store by this application. Content is held in memory only for as long as it takes to answer a request. Any conversation or summary that persists does so inside the owner's local OpenCode session storage, under the owner's control.

Retention

Tokens persist on the local machine until the owner deletes them or revokes access. Chat history and any generated summaries persist according to the owner's own local settings for OpenCode, not this application.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions by removing this application. Revocation takes effect immediately: the refresh token stops working, and the local programs can no longer call Google's APIs. Deleting the local token files has the same practical effect.

Children

This application is not directed at anyone, including children. It has a single adult user.

Changes

If this policy changes, the revised version will be posted at this URL with a new effective date. Given the single-user scope, changes are unlikely.
